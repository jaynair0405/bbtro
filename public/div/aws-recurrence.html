JPO Rules — Reference (BB.TRSO.EMU.16)

Responsibility for a repeated AWS act is fixed by the first rule it satisfies. Weeks are counted Friday to Thursday.

RuleWindowConditionResponsibility
Rule 1Per tripIn one trip AWS acts ≥3 times AND ≥2 of them fall on consecutive signals.Cab side
Rule 2Per day>2 acts on the same signal (magnet) in the same day.S&T
Rule 3aPer week>3 acts on the same cab in one Fri–Thu week.Cab side
Rule 3bPer week≥3 acts on the same magnet in one Fri–Thu week.S&T
Rule 4—Any act matching none of the above.Transient

Peak / 7d in this report is the maximum number of acts on a magnet/cab within any rolling 7-day window over the period. It is the escape-proof indicator for the weekly rules: peak ≥3 on a magnet → Rule 3b, peak ≥4 on a cab → Rule 3a, caught even when the run straddles a calendar-week boundary (the reason this report uses a 14-day floor, not 7).
