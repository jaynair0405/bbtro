Writing a cadre letter

This replaces the Word file on the office share. The letterhead, signature block and table layouts are built in, so what you write is the content — not the formatting.

The five minutes version

  1. Press ＋ New letter and pick the type. That fills in the addressee, subject, body and the right table columns.
  2. Fill the boxes in Fill-ins — they are the blanks in the letter text.
  3. Add the staff: search by PF number or name, add a blank row, or paste a block from Excel.
  4. Check the paper on the right. It is exactly what will print.
  5. Finalise & file, then Print.

Fill-ins

Anywhere the letter text contains {{something}}, a box for it appears in the Fill-ins panel. Type a value and it drops into the letter everywhere it is used. You can add your own — type {{lobby}} in the body and a "lobby" box appears.

Two fill themselves and have no box: {{count}} follows the number of rows in the table, and {{letter_date}} follows the date. So a letter that reads "transfer 35 Sr. Assistant Loco Pilots" stays right when you add or remove a name.

Anything you leave empty prints as ‹name› in angle brackets — deliberately visible, so a half-finished letter can never be signed by mistake. You get a warning listing them when you finalise.

The staff table

Three ways to add rows

Search Type at least 2 characters of a PF number, name or CMS ID. Picks up any active staff member, in any lobby. Their PF number, name, designation and present lobby fill themselves.
＋ Blank row For people not on the staff records yet — trainee ALPs arriving from ZRTI, for instance. Type everything by hand.
⇩ Paste from Excel Copy the block of cells in Excel, paste, check the column mapping, add. This is how a 69-name relieving letter takes ten seconds.

Use ⛶ Grid editor for the wide view — every column of the table, editable in place. Rows picked from the staff records show a green edge; those are linked, so the letter can be found later by searching for that person's name.

Notes vs letters

A few types are internal NOTES rather than letters — the refresher exemption, for example. They print with a centred NOTE heading, are signed without a place line, and carry the approval chain (ADEE → DEE → Sr.DEE) at the foot. The Closing panel shows the approval-chain box only for those.

Numbering

The number is suggested from the sub-series you pick and a day-wise serial, and stays editable — type over it whenever the file demands something else. Changing the sub-series or date re-suggests it, but never overwrites a number you typed yourself.

Finalising

Finalising locks the letter and files a copy into the Documents repository under Cadre letters, in a folder named after the family. From there anyone in the division can find and reprint it.

Made a mistake after filing? A division admin can Reopen the letter. That pulls the filed copy back out of the repository and returns the letter to draft.

Printing

Print uses the browser's print dialog — choose Save as PDF for a file, or your printer for paper. Set paper size to A4 and leave headers and footers off. The preview shows an estimated page count when a letter runs past one page; table headings repeat on every page and no row is ever split across a page break.
