B. Making the Daily Position

  1. The sheet date is today — set for you

    Position for: Today is the date of the sheet (the day you download and send the position to officers). It is filled in and locked; never set a report's own date there. The CMS files carry no date, so every report is saved under its own data date, worked out from the sheet date:
    Data dateReports
    Sheet date (D-0)CLI Monitoring Due, Kiosk Detail
    Yesterday (D-1)WR WOR Lobby Wise, WR WOR HQ Wise, FSD, Continuous Night Working, Change on Approval, PME/REFT/ASIG Overdue, PR Overdue, Sign On/Off without Biometric, Breach of Rest
    Day before (D-2)Working Hours Mainline, Working Hours Suburban, PDD, Sign On – Sign Off Biometric
    Each report's heading shows its data date in brackets. Making up a missed day? Press Making an older sheet? and pick the date that sheet was due — still not the reports' dates.

  2. Check the confirm box

    Nothing is saved straight away. Every upload — all files at once, + Add files, a tab, or Fill by hand — first shows a Save these reports? box listing each report recognised with whose data it is (today's, yesterday's, day before yesterday), and ⚠ replaces saved where that day already has it. Files it could not recognise are listed too. Nothing to choose — check and press Confirm & save.

  3. Drop all the ordinary downloads at once

    Drag the CSV files onto the box, or Choose CSV files. File names do not matter. A file the page does not recognise is listed with the reason; the rest still load. Once the day's reports are showing, more files can be dropped anywhere on them, or added with + Add files.

  4. Files that look alike go in tabs

    • Continuous Night Working — 3 nights / 4 nights / >4 nights.
    • Sign On/Sign Off without Biometric — Lobby summary / CSTS list / KYNS list / PNVS list / DR / LTT.
    Pick the tab, then choose that file.

  5. Fill by hand when there is no file

    Fill by hand → choose the report (PR Overdue, Lobbywise Breach of Rest, DR / LTT) → type the counts → Save. It replaces that report if one is already loaded.

  6. Read the page

    • The chip strip at the top ticks each report loaded for the day; an unticked chip is a gap.
    • Red figures are the ones to look at (e.g. FSD not carried, duty over 12 hours).
    • Warnings in the yellow box mean a total did not add up or a lobby is missing — usually a wrong CMS filter. Re-download.
    • Many counts can be clicked to list the crew behind them.

  7. Saving and reloading

    Every upload and hand entry is saved automatically. Loading the same report again for the same day replaces it (the earlier one is kept as history) — normal when a later download catches late sign-offs. Picking a date that is already saved opens it, so a day can be added to or exported later. To open an earlier day, use Older sheet? at the top and pick that sheet's date; Back to today returns.

  8. A report saved under the wrong date

    Press Change date next to the report's date, pick its correct data date (the box shows which sheet that belongs to) and Move. If that date already has the report, you are asked before it is replaced. Nothing is deleted — the earlier copies are kept as history. The button is on the page only, never in the PDF or Excel.

  9. Export

    • Position (one view) — PDF / Excel: the two-page A4 sheet that goes to officers.
    • Whole day — PDF / Excel: every report one after another; tick Include detail tables for the extra tables, otherwise only the sheet blocks print.
